# Skills — test &amp; validate passes

Reusable skills for validating Apple Wallet & Google Wallet passes and reproducing issues firsthand — pair them with the CLI and MCP.

## Coming soon
- **pass-test** — run API tests in natural language
- **pass-scenario** — BDD-style Given / When / Then pass tests
- **pass-diagnose** — understand why a pass failed
- **pass-validate-field** — check one field (barcode, nfc, colors…) across pass types
- **apple-pass-test / google-pass-test** — platform-specific validation
