# CLI

A cross-platform command-line tool (macOS, Windows, Linux) for creating and managing wallet passes from the terminal — built to be driven by both humans and AI agents.

## Install
- **macOS / Linux** (Homebrew): see [flomio/passninja-cli](https://github.com/flomio/passninja-cli)
- **Windows** (PowerShell): see the SDK / CLI guide at https://passninja.com/docs
