# Tools

How-tos and examples for the developer tooling around wallet passes.

- **[CLI](cli/)** — create & manage passes from the terminal (macOS, Windows, Linux)
- **[MCP](mcp/)** — drive passes from AI agents via the Model Context Protocol
- **[Skills](skills/)** — test & validate passes and reproduce issues firsthand
