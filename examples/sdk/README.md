# SDKs

Official PassNinja client libraries for creating Apple Wallet & Google Wallet passes. One folder per language, each with runnable examples.

| Language | Install | Source |
|----------|---------|--------|
| [Node.js](node/) | `npm install @passninja/passninja-js` | [flomio/passninja-js](https://github.com/flomio/passninja-js) |
| [Python](python/) | `pip install passninja` | [flomio/passninja-python](https://github.com/flomio/passninja-python) |
| [PHP](php/) | `composer require passninja/passninja` | [flomio/passninja-php](https://github.com/flomio/passninja-php) |
| [Ruby](ruby/) | `gem install passninja` | [PassNinja SDKs](https://passninja.com/documentation/sdks) |
| [Java](java/) | Maven — see SDKs page | [PassNinja SDKs](https://passninja.com/documentation/sdks) |
| [C#](csharp/) | NuGet — see SDKs page | [PassNinja SDKs](https://passninja.com/documentation/sdks) |

Official SDK index: https://passninja.com/documentation/sdks

_Part of [open-wallet](../../README.md)._
