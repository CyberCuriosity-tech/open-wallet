# REST API — curl

Create and manage Apple Wallet & Google Wallet passes over the PassNinja REST API — predictable JSON in, predictable JSON out. Every example here is a copy-paste `curl` request paired with its JSON response.

> Full API reference: https://passninja.com/docs
