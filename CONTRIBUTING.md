# Contributing to open-wallet

Thanks for helping make wallet passes easier to understand.

## Ways to help
- **Fix an error.** Wrong field, stale behavior, broken example? Open a PR — use the *Edit on GitHub* link at the top of any docs page.
- **Add clarity.** A better explanation, a clearer diagram, a real-world example.
- **Fill a gap.** See a 🚧 item in the [README](README.md) roadmap you can write? Open an issue to claim it first.

## Principles
We hold docs to a simple bar:
1. **Concept before syntax.** Explain what something *means* and *why you'd use it* before the reference table.
2. **Show, don't just tell.** Every concept earns a copy-paste example.
3. **Plain language.** Write for a developer seeing this for the first time.
4. **Accurate over complete.** Cite Apple/Google sources; when behavior varies by OS version, say so.

## Pages
Docs are static HTML in `docs/`, served via GitHub Pages — no build step. Keep pages self-contained and match the existing style.
